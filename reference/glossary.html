Module 0 · Review and Toolkit

Function
A rule that gives exactly one output for each allowed input. 0.3
Domain, range
The allowed inputs of a function, and the outputs it can actually produce. 0.3
Slope
How much the output changes when the input increases by 1. For a line, change in y divided by change in x. 0.4
Residual
True value minus predicted value for one data point. 0.4
MSE (mean squared error)
The average of the squared residuals. 0.4
Vertex
The lowest or highest point of a parabola. 0.5
Discriminant
b² − 4ac. Its sign tells how many real roots a quadratic has. 0.5
Sigmoid
σ(z) = 1 / (1 + e^(−z)). Turns any number into a value between 0 and 1. 0.6
Decision boundary
The input value where a classifier switches sides; for the sigmoid, where the score z is 0. 0.6
Convergent sum
A sum of infinitely many terms whose total settles at a finite number. 0.7
Derivative
The slope of a curve at a point: how fast the output changes per unit change of input there. 0.8
Chain rule
Derivative of a function inside a function: derivative of the outside, times derivative of the inside. 0.8
Partial derivative
The derivative with respect to one variable while the others are held fixed. 0.9
Gradient descent
Repeatedly stepping a weight against the derivative of the loss: w ← w − η · L′(w). 0.9
Learning rate
The step size η in gradient descent. 0.9

Module 1 · Part A · Vectors and the Matrix-Vector Product

Vector
An ordered list of numbers. Drawn as an arrow from the origin; read as one row of data. 1.1
Component
One of the numbers in a vector. v₁ is the first, v₂ the second. 1.1
Rⁿ
The space of all vectors with n components. 1.1
Zero vector
The vector whose components are all 0. 1.1
Scalar
An ordinary number, when it is used to scale a vector. 1.2
Norm
The length of a vector: the square root of the sum of its squared components. Written ‖v‖. 1.3
Distance
Between two points a and b: the norm of a − b. 1.3
Unit vector
A vector of length 1. Normalising means dividing a vector by its norm to get one. 1.3
Dot product
Multiply matching components and add. Returns one number. 1.4
Orthogonal
Perpendicular. Two vectors are orthogonal exactly when their dot product is 0. 1.5
Cosine similarity
The cosine of the angle between two vectors: dot product divided by the product of the norms. Ignores length. 1.5
Projection
The part of a that lies along b: c·b with c = (a·b)/(b·b). The closest point to a on the line of b. 1.6
Linear combination
Scale some vectors and add the results: c₁v + c₂w. 1.7
Coefficient
One of the numbers c₁, c₂ that scale the vectors in a linear combination. 1.7
Span
All the vectors you can reach with linear combinations of a given set. 1.7
Linearly dependent
For two vectors: lying on the same line, so one is a multiple of the other and adds no new direction. 1.7
Linearly independent
For two vectors: not on the same line, so each adds a direction the other cannot. 1.7
Standard basis vectors
(1, 0) and (0, 1) in the plane. Every vector is a combination of them with its own components as coefficients. 1.7
Matrix
A rectangular table of numbers. As data: one row per example, one column per feature. 1.8
Shape
Rows × columns of a matrix, in that order. 1.8
Matrix-vector product
Row view: the dot product of each row with the vector. Column view: a linear combination of the columns. 1.8, 1.9
Identity matrix
The matrix with 1s on the diagonal and 0s elsewhere. Multiplying by it leaves a vector unchanged. 1.8
Column space
The span of the columns of a matrix: every output Ax can produce. 1.9

Module 1 · Part B · Transformations, Systems and the Inverse

Transformation
A function that takes vectors to vectors. A matrix A gives the transformation x → Ax. 1.11
Linear transformation
One that respects adding and scaling: A(u + v) = Au + Av and A(cu) = c(Au). Grid lines stay straight and the origin stays fixed. 1.11
Diagonal matrix
A matrix with non-zero numbers only on the main diagonal. It stretches each axis separately. 1.12
Shear
A move that slides points sideways in proportion to their height. 1.12
Matrix product AB
The single matrix that does B first and then A. Slot (i, j) is row i of A dotted with column j of B. 1.13
Transpose
Aᵀ: the matrix with the rows of A written as columns. 1.14
Symmetric matrix
A square matrix equal to its own transpose. 1.14
System of linear equations
Several linear equations in the same unknowns, written together as Ax = b. 1.15
Augmented matrix
The coefficient matrix A with the right-hand side b attached as an extra column. 1.16
Elimination
Using row operations to create zeros below the diagonal so the system can be solved from the bottom up. 1.16
Back-substitution
Solving a triangular system from the last equation upward. 1.16
Pivot
The first non-zero number in a row during elimination; the one used to clear the entries below it. 1.16
Inverse matrix
A⁻¹: the matrix that undoes A, so that A⁻¹A = I. 1.17
Invertible, singular
Invertible: has an inverse. Singular: has none, because it collapses space. 1.17
Determinant (2 × 2)
The number ad − bc. Zero exactly when the matrix is singular. Studied fully in Part C. 1.17
Rank
The number of linearly independent columns; the number of dimensions the outputs Ax fill. 1.18
Full rank
Rank as large as the shape allows. For a square matrix, the same as invertible. 1.18
Null space
All vectors x that the matrix sends to zero: Ax = 0. 1.18
Collinearity
Feature columns that are multiples or combinations of each other, so the data matrix loses rank. 1.18
Residual vector
r = y − Xw: truth minus prediction for every data point at once. 1.19
Least squares
Choosing w to make the squared length of the residual as small as possible. 1.19
Normal equations
XᵀX w = Xᵀy: the condition that the residual is perpendicular to every column of X. 1.19

Module 1 · Part C · Determinants and Eigenvectors

Determinant
For a 2 × 2 matrix, ad − bc. Its size is the factor by which the matrix scales areas (volumes for 3 × 3); a negative sign means a flip; zero means singular. 1.21, 1.22
Minor
The smaller determinant left after crossing out one row and one column; used to expand a 3 × 3 determinant. 1.22
Triangular matrix
A matrix with zeros below (or above) the diagonal. Its determinant and its eigenvalues come straight from the diagonal. 1.22, 1.26
Basis
A set of linearly independent vectors that can reach every vector in the space. A basis of Rⁿ has exactly n vectors. 1.23
Coordinates in a basis
The coefficients that build a vector from the basis vectors. Written [v]_B. 1.23
Change-of-basis matrix
The matrix B whose columns are the basis vectors: v = B[v]_B and [v]_B = B⁻¹v. 1.23
Similar matrices
A and B⁻¹AB: the same move described in two different bases. 1.24
Eigenvector
A non-zero vector v that the matrix does not turn: Av = λv. 1.25
Eigenvalue
The number λ in Av = λv: the stretch factor along an eigenvector. 1.25
Characteristic equation
det(A − λI) = 0. Its solutions are the eigenvalues. For 2 × 2: λ² − (trace)λ + det = 0. 1.26
Trace
The sum of the diagonal entries of a square matrix. It equals the sum of the eigenvalues. 1.26
Eigenpair
An eigenvalue together with one of its eigenvectors. 1.27
Steady state
A vector left unchanged by a repeated process: an eigenvector with eigenvalue 1. 1.29
Dominant eigenvector
The eigenvector whose eigenvalue has the largest size; repeated application pulls vectors toward it. 1.29

Module 1 · Part D · Diagonalization, SVD and PCA

Diagonalization
A = PDP⁻¹. The columns of P are an eigenvector basis and D holds the matching eigenvalues. 1.31
Orthonormal
Perpendicular to one another and each of length 1. If Q is square with orthonormal columns, Q⁻¹ = Qᵀ. 1.32
Spectral theorem
Every real symmetric matrix has real eigenvalues and an orthonormal eigenvector basis. 1.32
Singular value decomposition (SVD)
A = UΣVᵀ. Read input coordinates along the columns of V, stretch by the diagonal of Σ, and rebuild along the columns of U. 1.33
Singular value
Nonnegative stretch σᵢ. Its square is an eigenvalue of AᵀA, and Avᵢ = σᵢuᵢ for a paired set of axes. 1.34
Outer product
A column times a row. Each row of the resulting matrix is the original row scaled by one entry of the column. 1.35
Truncated SVD
The approximation that keeps the k largest singular-value pieces. Its squared Frobenius error is the sum of squares of the omitted singular values. 1.35
Centering
Subtracting each feature’s mean from every value in its column. 1.36
Sample variance and covariance
Divide the sum of squared deviations, or of paired deviations multiplied together, by n − 1. 1.36
Covariance matrix
C = XcᵀXc/(n − 1) for centered data. Diagonal entries are the feature variances. The other entries are their paired covariances. 1.36
Principal component analysis (PCA)
Projecting centered rows onto perpendicular unit directions of greatest variance, chosen in order. Each direction is a covariance eigenvector. A score is the row’s dot product with the direction. 1.37
Explained variance ratio
The variance along a principal direction divided by the total variance, when the total is positive. 1.37
