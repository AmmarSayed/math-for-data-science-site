Vectors and the Matrix-Vector Product

Linear algebra is the language data is written in. A row of a spreadsheet is a vector. The whole spreadsheet is a matrix. A model's prediction for every row at once is a matrix times a vector. This part builds those three ideas from the ground up.

How this part is written. Every technique is shown one step at a time before it is used, with the reason for each step. Anything you have probably not met before carries a New tag. Some topics here (vectors, dot product, projection) you have studied before; they are still taught in full, so nothing depends on memory.

Lesson 1.1

What a vector is

Goal: read a vector three ways: as a list of numbers, as an arrow, and as one row of data.

Every data point a model sees is a vector. An apartment described by its area and number of rooms is the vector (120, 3). A customer described by 50 measurements is a vector with 50 numbers. Learn what you can do with one vector and you know what a model does with every row of your data.

LAB 1.1 · drag the circle at the tip of the arrow
  • Put the tip at (4, 1), then at (1, 4). Same two numbers, different arrows. So does the order of the numbers matter?
  • Make the first component negative. Which way does the arrow go?
  • Drag the tip onto the centre. What are the components then?

The idea, in three steps

  1. A vector is an ordered list of numbers. We write it in brackets: \(v = (3, 2)\). Each number is called a component. The first component is written \(v_1\) and the second \(v_2\). Here \(v_1 = 3\) and \(v_2 = 2\). Order matters: (3, 2) and (2, 3) are different vectors, as the lab shows.
  2. You can draw it as an arrow. Start at the origin (0, 0). The first component says how far to go sideways (right if positive, left if negative). The second says how far to go vertically (up if positive, down if negative). The arrow runs from the origin to where you land.
  3. You can read it as one row of data. If the two numbers are "area in hundreds of m²" and "number of rooms", then (1.2, 3) is one apartment. Nothing about the maths changes; only the meaning you attach to the numbers.

How many components? A vector with 2 components lives in \(\mathbb{R}^2\) (read "R two"), the flat plane you see in the lab. One with 3 components lives in \(\mathbb{R}^3\), ordinary 3D space. One with n components lives in \(\mathbb{R}^n\). You cannot draw \(\mathbb{R}^{50}\), but every rule in this part works the same way there, which is why we practise in 2D where you can see it.

Writing conventions you will see. Books write a vector as a bold letter \(\mathbf{v}\) or with an arrow \(\vec{v}\), and often stack the components vertically as a column: \(\begin{pmatrix} 3 \\ 2 \end{pmatrix}\). It is the same object as (3, 2). The vector whose components are all zero is the zero vector.

Worked example

Three employees are described by (years of experience, training courses completed):

EmployeeVectorReading
A(2, 5)2 years, 5 courses
B(8, 1)8 years, 1 course
C(8, 6)8 years, 6 courses

Each is a point in \(\mathbb{R}^2\). B and C share the first component, so on a plot C sits directly above B. Add a third measurement, salary, and each becomes a vector in \(\mathbb{R}^3\).

Practice on paper

  1. Sketch the vector (−2, 3). Describe the walk from the origin in words.
  2. Which space does (5, 0, −1, 2) live in?
  3. For \(u = (7, -4, 9)\), what are \(u_1\) and \(u_3\)?
  4. A student scored 80 in maths, 65 in statistics and 90 in Python. Write this as a vector and name its space.
  5. Are (1, 2) and (2, 1) the same vector? Why?
Solutions

1. Go 2 to the left, then 3 up. The arrow points up and to the left.

2. It has 4 components, so \(\mathbb{R}^4\).

3. \(u_1 = 7\) (first), \(u_3 = 9\) (third).

4. (80, 65, 90), in \(\mathbb{R}^3\).

5. No. A vector is an ordered list. (1, 2) goes 1 right and 2 up; (2, 1) goes 2 right and 1 up.

Python

import numpy as np

v = np.array([3, 2])
print(v[0], v[1])      # 3 2   (Python counts from 0, so v[0] is the first component)
print(v.shape)         # (2,)  -> two components

employee = np.array([8, 6, 42000])   # years, courses, salary
print(employee.shape)  # (3,)  -> a vector in R^3

Lesson 1.2

Adding and scaling

Goal: add two vectors and multiply a vector by a number, by hand and as a picture.

These are the only two operations linear algebra is built from. Averaging two data points, moving a weight during training, mixing two signals: each is an addition, a scaling, or both.

LAB 1.2a · addition: drag the tips of a and b
  • Follow the solid a, then the dashed copy of b. Then follow the solid b, then the dashed copy of a. Do both routes end at the same place?
  • Set b to exactly the opposite of a. What is the sum?
LAB 1.2b · scaling: drag v, then move the slider
  • Move c from 1 to 2 to 3. Does the arrow ever leave its line?
  • Make c negative. Make c equal to 0. What happens each time?

Addition, step by step

To add two vectors, add the components that sit in the same position.

  1. Write them one above the other: \(a = (2, 1)\) and \(b = (1, 3)\).
  2. Add the first components: \(2 + 1 = 3\).
  3. Add the second components: \(1 + 3 = 4\).
  4. Put the results in the same order: \(a + b = (3, 4)\).

In general: \(a + b = (a_1 + b_1,\ a_2 + b_2)\). As a picture: walk along a, then along b; where you finish is the tip of \(a + b\). The order does not matter, \(a + b = b + a\), which is the two routes in Lab 1.2a.

Rule. You can only add vectors with the same number of components. (2, 1) + (1, 3, 5) has no meaning.

Scaling, step by step

To multiply a vector by a number, multiply every component by that number. In this context an ordinary number is called a scalar, because it scales the vector.

  1. Take \(v = (2, 1)\) and the scalar \(c = 3\).
  2. Multiply the first component: \(3 \times 2 = 6\).
  3. Multiply the second component: \(3 \times 1 = 3\).
  4. Result: \(3v = (6, 3)\). Same direction, three times as long.

A negative scalar flips the direction: \(-1 \cdot (2, 1) = (-2, -1)\). A scalar of 0 gives the zero vector.

Subtraction is both together

\(a - b\) means \(a + (-1)\,b\): flip b, then add. In components you simply subtract position by position: \((2, 1) - (1, 3) = (2 - 1,\ 1 - 3) = (1, -2)\).

A useful picture: \(a - b\) is the arrow that takes you from the tip of b to the tip of a. Check: start at b = (1, 3), add (1, −2), and you arrive at (2, 1) = a. This is used in the next lesson to measure distance.

Worked example

Two customers are described by (visits per month, average basket in hundreds of EGP): \(p = (4, 6)\) and \(q = (10, 2)\). Find the "average customer".

  1. Add: \(p + q = (4 + 10,\ 6 + 2) = (14, 8)\).
  2. Scale by one half: \(\tfrac12 (14, 8) = (7, 4)\).

The average customer makes 7 visits with a basket of 400 EGP. On a plot, (7, 4) is exactly midway between the two points. The mean of a whole dataset is this same operation with more vectors.

Practice on paper

Use \(a = (4, -1)\) and \(b = (-2, 5)\).

  1. \(a + b\)
  2. \(a - b\)
  3. \(3a\)
  4. \(2a - 3b\)
  5. \(\tfrac12 (a + b)\). What does this vector represent?
  6. Which vector must you add to a to reach b?
Solutions

1. \((4 + (-2),\ -1 + 5) = (2, 4)\).

2. \((4 - (-2),\ -1 - 5) = (6, -6)\). Careful with the double minus: \(4 - (-2) = 4 + 2\).

3. \((3 \times 4,\ 3 \times (-1)) = (12, -3)\).

4. First scale each: \(2a = (8, -2)\) and \(3b = (-6, 15)\). Then subtract: \((8 - (-6),\ -2 - 15) = (14, -17)\).

5. From problem 1, \(a + b = (2, 4)\), and half of it is \((1, 2)\). It is the midpoint (the average) of a and b.

6. You need \(b - a\), the arrow from the tip of a to the tip of b: \((-2 - 4,\ 5 - (-1)) = (-6, 6)\). Check: \(a + (-6, 6) = (-2, 5) = b\).

Python

import numpy as np

b = np.array([-2, 5])

print(a - b)          # [ 6 -6]
print(3 * a)          # [12 -3]
print(2*a - 3*b)      # [ 14 -17]
print((a + b) / 2)    # [1. 2.]   the midpoint

Lesson 1.3

Length and distance

Goal: compute the length of a vector and the distance between two data points.

"How similar are these two customers?" becomes "how far apart are their vectors?". Nearest-neighbour methods and clustering run entirely on distance. The error of a model is the length of the vector of its mistakes.

LAB 1.3 · drag a and b
  • Put a at (3, 4). Look at the grey dashed triangle. Which side is the arrow?
  • Find three different positions for a that all have length exactly 5.
  • Put a and b on the same point. What is the distance?

Length, step by step

The arrow for \(v = (3, 4)\), its sideways part and its vertical part form a right-angled triangle. The arrow is the longest side. Pythagoras' theorem says: (longest side)² = (side 1)² + (side 2)².

  1. Square each component: \(3^2 = 9\) and \(4^2 = 16\).
  2. Add the squares: \(9 + 16 = 25\).
  3. Take the square root: \(\sqrt{25} = 5\).

The length of a vector is called its norm and is written with double bars: \(\lVert v \rVert = 5\). In general $$\lVert v \rVert = \sqrt{v_1^2 + v_2^2}$$ With more components, keep adding squares: \(\lVert v \rVert = \sqrt{v_1^2 + v_2^2 + \dots + v_n^2}\).

Two things to watch. A negative component still contributes a positive amount, because squaring removes the sign: for (−3, 4), \((-3)^2 = 9\). And the square root often does not simplify: for (1, 2, 3) the sum of squares is \(1 + 4 + 9 = 14\), and \(\sqrt{14} \approx 3.742\) stays as \(\sqrt{14}\), since \(14 = 2 \times 7\) has no repeated factor.

Distance, step by step

From Lesson 1.2, \(a - b\) is the arrow from the tip of b to the tip of a. So the distance between the two points is the length of that arrow.

  1. Take \(a = (4, 6)\) and \(b = (1, 2)\).
  2. Subtract: \(a - b = (4 - 1,\ 6 - 2) = (3, 4)\).
  3. Find the length of the result: \(\sqrt{3^2 + 4^2} = \sqrt{25} = 5\).

So \(\text{distance}(a, b) = \lVert a - b \rVert\). The order does not matter: \(b - a = (-3, -4)\) has the same length.

Unit vectors New name

A unit vector is a vector of length exactly 1. It keeps only the direction. To turn any non-zero vector into a unit vector, divide it by its own length.

  1. Start with \(v = (3, 4)\), whose length is 5.
  2. Divide every component by 5: \(\left(\tfrac35, \tfrac45\right) = (0.6, 0.8)\).
  3. Check the length: \(\sqrt{0.6^2 + 0.8^2} = \sqrt{0.36 + 0.64} = \sqrt{1} = 1\).

This is called normalising the vector. It is written \(\hat{v} = \dfrac{v}{\lVert v \rVert}\).

Practice on paper

  1. \(\lVert (6, 8) \rVert\)
  2. \(\lVert (1, -2, 2) \rVert\)
  3. \(\lVert (2, 3) \rVert\). Leave it as a root, then give a decimal.
  4. The distance between (1, 2) and (4, 6).
  5. The unit vector in the direction of (0, −5).
  6. Take \(a = (3, 0)\) and \(b = (0, 4)\). Is \(\lVert a + b \rVert\) equal to \(\lVert a \rVert + \lVert b \rVert\)?
Solutions

1. \(36 + 64 = 100\), and \(\sqrt{100} = 10\).

2. \(1 + 4 + 4 = 9\), and \(\sqrt9 = 3\). Note \((-2)^2 = 4\), not −4.

3. \(4 + 9 = 13\). \(\sqrt{13}\) does not simplify (13 is prime). As a decimal, about 3.606.

4. Subtract: \((4 - 1,\ 6 - 2) = (3, 4)\). Length: \(\sqrt{9 + 16} = 5\).

5. Length is \(\sqrt{0 + 25} = 5\). Divide: \((0/5,\ -5/5) = (0, -1)\).

6. No. \(a + b = (3, 4)\) has length 5, but \(\lVert a \rVert + \lVert b \rVert = 3 + 4 = 7\). Walking straight is shorter than walking the two sides. In general \(\lVert a + b \rVert \le \lVert a \rVert + \lVert b \rVert\), called the triangle inequality.

Python

import numpy as np

v = np.array([3, 4])
print(np.linalg.norm(v))             # 5.0
print(np.sqrt(np.sum(v**2)))         # 5.0, the same thing written out

a, b = np.array([4, 6]), np.array([1, 2])
print(np.linalg.norm(a - b))         # 5.0  distance

unit = v / np.linalg.norm(v)
print(unit, np.linalg.norm(unit))    # [0.6 0.8] 1.0

Lesson 1.4

The dot product

Goal: compute a dot product and say what its sign tells you.

The dot product is the single most used operation in machine learning. A linear model's prediction is a dot product of weights and features. Every neuron in a neural network starts by computing one.

LAB 1.4 · drag a and b and watch the sign
  • Keep a fixed. Swing b around in a full circle. Where is the dot product positive, where negative?
  • Find a position of b where the dot product is exactly 0. What do you notice about the two arrows?
  • Put b on top of a. Compare the result with the length of a from Lesson 1.3.

How to compute it, step by step

The dot product takes two vectors of the same size and returns one number.

  1. Take \(a = (2, 3)\) and \(b = (4, 1)\).
  2. Multiply the first components: \(2 \times 4 = 8\).
  3. Multiply the second components: \(3 \times 1 = 3\).
  4. Add the products: \(8 + 3 = 11\).

So \(a \cdot b = 11\). In general, for vectors with n components: $$a \cdot b = a_1 b_1 + a_2 b_2 + \dots + a_n b_n = \sum_{i=1}^{n} a_i b_i$$ The last form is the sigma notation from Module 0, Lesson 0.7: pair up, multiply, add.

Do not confuse it with addition. \(a + b\) gives a vector, (6, 4). \(a \cdot b\) gives a single number, 11.

First meaning: a weighted total

A shop sells 3 notebooks and 2 pens. A notebook costs 20, a pen costs 5. Quantities are \(q = (3, 2)\), prices are \(p = (20, 5)\).

\(q \cdot p = 3 \times 20 + 2 \times 5 = 60 + 10 = 70\). That is the bill. Whenever you multiply matching items and add up, you are computing a dot product.

A linear model does exactly this. With weights \(w\), features \(x\) and a bias \(b\), the prediction is \(\hat{y} = w \cdot x + b\). The line \(\hat{y} = wx + b\) from Module 0 is the case with a single feature.

Second meaning: do the arrows agree?

The lab shows the pattern:

Dot productThe arrows
positivepoint broadly the same way (angle less than 90°)
zeroare perpendicular (angle exactly 90°)
negativepoint broadly opposite ways (angle more than 90°)

Lesson 1.5 explains why. For now, treat it as an observation from the lab.

Three properties worth knowing

  • Order does not matter: \(a \cdot b = b \cdot a\), because \(2 \times 4 = 4 \times 2\).
  • A vector dotted with itself gives its length squared: \(a \cdot a = a_1^2 + a_2^2 = \lVert a \rVert^2\). For (3, 4): \(9 + 16 = 25 = 5^2\).
  • It distributes over addition: \((a + b) \cdot c = a \cdot c + b \cdot c\).

Practice on paper

  1. \((1, 2, 3) \cdot (4, -5, 6)\)
  2. \((2, -1) \cdot (1, 2)\). What does the answer tell you about the two arrows?
  3. \(a \cdot a\) for \(a = (3, 4)\). Compare with \(\lVert a \rVert\).
  4. A model has weights \(w = (0.5, 2)\) and bias 1. Predict for the input \(x = (10, 3)\).
  5. Check the third property with \(a = (1, 2)\), \(b = (3, 0)\), \(c = (2, 1)\).
  6. Can you compute \((1, 2) \cdot (3, 4, 5)\)?
Solutions

1. \(1 \times 4 + 2 \times (-5) + 3 \times 6 = 4 - 10 + 18 = 12\).

2. \(2 \times 1 + (-1) \times 2 = 2 - 2 = 0\). The arrows are perpendicular.

3. \(9 + 16 = 25\). The length is 5, and \(5^2 = 25\).

4. \(w \cdot x = 0.5 \times 10 + 2 \times 3 = 5 + 6 = 11\). Add the bias: \(11 + 1 = 12\).

5. Left side: \(a + b = (4, 2)\), and \((4, 2) \cdot (2, 1) = 8 + 2 = 10\). Right side: \(a \cdot c = 2 + 2 = 4\) and \(b \cdot c = 6 + 0 = 6\), total 10. Equal.

6. No. The vectors have different numbers of components, so the pairs do not match up.

Python

import numpy as np

a, b = np.array([2, 3]), np.array([4, 1])
print(np.dot(a, b))     # 11
print(a @ b)            # 11   (@ is the same operation)
print(np.sum(a * b))    # 11   multiply matching entries, then add

w, x, bias = np.array([0.5, 2]), np.array([10, 3]), 1
print(w @ x + bias)     # 12.0  a linear model's prediction

What kind of object is \((1, 5) \cdot (2, 3)\)?

Lesson 1.5

Angles and perpendicular vectors

Goal: find the angle between two vectors, and explain why a dot product of zero means a right angle.

Two documents, two customers or two word meanings are "similar" when their vectors point the same way, whatever their lengths. That measure is called cosine similarity and it is how search engines and language models compare things.

LAB 1.5 · drag a and b; the green arc is the angle θ
  • Make the angle 90°. What is cos θ? What is the dot product?
  • Keep the direction of b but make it twice as long. Does cos θ change? Does the dot product?
  • Point b exactly opposite to a. What is cos θ?

A reminder about cosine

You only need one fact about the cosine function here: it turns an angle into a number between −1 and 1 that says how much two directions agree.

Angle θcos θMeaning
0°1exactly the same direction
60°0.5partly the same
90°0perpendicular: no agreement
120°−0.5partly opposite
180°−1exactly opposite

The formula that links dot product and angle

For any two non-zero vectors, with θ the angle between them: $$a \cdot b = \lVert a \rVert\,\lVert b \rVert \cos\theta$$ In words: the dot product equals the two lengths multiplied together, scaled by how much the directions agree. Rearranged to find the angle: $$\cos\theta = \frac{a \cdot b}{\lVert a \rVert\,\lVert b \rVert}$$ The lab computes both sides for you. A full proof needs the law of cosines from trigonometry; here we prove the one case that matters most, the right angle, further down.

This formula explains the sign table from Lesson 1.4. Lengths are always positive, so the sign of \(a \cdot b\) is the sign of \(\cos\theta\): positive under 90°, zero at 90°, negative above 90°.

Finding an angle, step by step

Find the angle between \(a = (1, 0)\) and \(b = (1, 1)\).

  1. Dot product: \(1 \times 1 + 0 \times 1 = 1\).
  2. Length of a: \(\sqrt{1 + 0} = 1\).
  3. Length of b: \(\sqrt{1 + 1} = \sqrt2 \approx 1.414\).
  4. Divide: \(\cos\theta = \dfrac{1}{1 \times 1.414} \approx 0.707\).
  5. Turn the cosine back into an angle with the inverse cosine key (\(\cos^{-1}\) or arccos): \(\theta = 45°\).

That matches the picture: (1, 1) runs along the diagonal, halfway between the two axes.

Why a dot product of zero means perpendicular

Two vectors that meet at a right angle are called perpendicular or orthogonal. The claim: a and b are orthogonal exactly when \(a \cdot b = 0\). Here is the reason, using only Pythagoras.

  1. Draw a and b from the origin. The third side of the triangle they make runs between their tips. From Lesson 1.2, that side is \(a - b\).
  2. Compute the squared length of that third side. In components, \(a - b = (a_1 - b_1,\ a_2 - b_2)\), so $$\lVert a - b \rVert^2 = (a_1 - b_1)^2 + (a_2 - b_2)^2$$
  3. Expand each bracket with \((p - q)^2 = p^2 - 2pq + q^2\): $$= a_1^2 - 2a_1b_1 + b_1^2 + a_2^2 - 2a_2b_2 + b_2^2$$
  4. Group the terms: \((a_1^2 + a_2^2) + (b_1^2 + b_2^2) - 2(a_1b_1 + a_2b_2)\). Each group is something you know: $$\lVert a - b \rVert^2 = \lVert a \rVert^2 + \lVert b \rVert^2 - 2\,(a \cdot b)$$
  5. Pythagoras says a triangle has a right angle between sides a and b exactly when (third side)² = (side a)² + (side b)², that is when \(\lVert a - b \rVert^2 = \lVert a \rVert^2 + \lVert b \rVert^2\).
  6. Compare steps 4 and 5. They agree exactly when the extra term \(-2\,(a \cdot b)\) is zero, which means \(a \cdot b = 0\).

So the dot product measures how far a triangle is from being right-angled. Zero means it is right-angled.

Cosine similarity New

When you only care about direction, use \(\cos\theta\) itself as the measure of similarity. It ignores length.

Example: three documents are described by how often they use the words (data, model). \(d_1 = (3, 1)\), \(d_2 = (6, 2)\), \(d_3 = (1, 3)\).

  1. \(d_1\) and \(d_2\): dot product \(18 + 2 = 20\). Lengths \(\sqrt{10}\) and \(\sqrt{40}\). Their product is \(\sqrt{400} = 20\). Cosine similarity \(= 20 / 20 = 1\).
  2. \(d_1\) and \(d_3\): dot product \(3 + 3 = 6\). Lengths \(\sqrt{10}\) and \(\sqrt{10}\), product 10. Cosine similarity \(= 6 / 10 = 0.6\).

\(d_2\) is \(d_1\) written twice as long: same mix of words, so similarity 1, even though the two points are far apart in distance. \(d_3\) has the opposite emphasis, so it scores lower.

Practice on paper

  1. Find the angle between (1, 1) and (−1, 1).
  2. Cosine similarity of (2, 0) and (1, 1).
  3. Find k so that (2, k) is orthogonal to (3, −6).
  4. Find the angle between (1, 2) and (−2, −4). Explain the result with a picture.
  5. Are (1, 2, −1) and (3, −1, 1) orthogonal?
  6. Two vectors have lengths 3 and 4 and meet at 60°. What is their dot product?
Solutions

1. Dot product: \(-1 + 1 = 0\). So \(\cos\theta = 0\) and the angle is 90°.

2. Dot product: \(2 + 0 = 2\). Lengths: 2 and \(\sqrt2 \approx 1.414\). \(2 / (2 \times 1.414) \approx 0.707\).

3. Set the dot product to zero: \(2 \times 3 + k \times (-6) = 0\), so \(6 - 6k = 0\), so \(k = 1\). Check: \((2, 1) \cdot (3, -6) = 6 - 6 = 0\).

4. Dot product: \(-2 - 8 = -10\). Lengths: \(\sqrt5\) and \(\sqrt{20}\), product \(\sqrt{100} = 10\). \(\cos\theta = -10 / 10 = -1\), so θ = 180°. The second vector is −2 times the first: same line, opposite direction.

5. \(3 - 2 - 1 = 0\). Yes, orthogonal. The test works in any number of dimensions.

6. \(3 \times 4 \times \cos 60° = 12 \times 0.5 = 6\).

Python

import numpy as np

def cosine(a, b):
    return (a @ b) / (np.linalg.norm(a) * np.linalg.norm(b))

d1, d2, d3 = np.array([3, 1]), np.array([6, 2]), np.array([1, 3])
print(cosine(d1, d2))    # 1.0
print(cosine(d1, d3))    # 0.6

a, b = np.array([1, 0]), np.array([1, 1])
print(np.degrees(np.arccos(cosine(a, b))))   # 45.0

You double the length of b without changing its direction. What happens to the cosine similarity of a and b?

Lesson 1.6

Projection

Goal: find the part of one vector that lies along another, in four steps.

Fitting a line to data is a projection: the model's predictions are the closest point it can reach to the true values, and the leftover error is perpendicular to everything the model can produce. PCA in Part D is projection again. This lesson is the first sight of both.

LAB 1.6 · drag a and b; the thick green arrow is the projection of a onto b
  • The grey dashed line drops from the tip of a to the line of b. At what angle does it meet that line?
  • Change only the length of b, keeping its direction. Does the green arrow move?
  • Swing a past 90° from b. Where does the projection go, and what sign does c take?
  • Make a perpendicular to b. What is the projection?

The picture

Imagine a light shining straight down onto the line through b. The projection of a onto b is the shadow a casts on that line. It answers the question: how much of a goes in the direction of b?

The shadow lies on the line of b, so it must be some multiple of b. Call that multiple c. The whole task is to find c.

Where the formula comes from, step by step

  1. The projection is \(c\,b\) for some number c that we do not know yet.
  2. The leftover part of a is what remains after removing the shadow: \(a - c\,b\). In the lab this is the grey dashed line.
  3. The shadow falls straight down, so the leftover is perpendicular to b. From Lesson 1.5, perpendicular means the dot product is zero: $$(a - c\,b) \cdot b = 0$$
  4. Distribute the dot product (third property in Lesson 1.4): $$a \cdot b - c\,(b \cdot b) = 0$$
  5. Move the second term across: \(a \cdot b = c\,(b \cdot b)\).
  6. Divide both sides by \(b \cdot b\): $$c = \frac{a \cdot b}{b \cdot b}$$

So the projection of a onto b is $$\text{proj}_b\,a = \left(\frac{a \cdot b}{b \cdot b}\right) b$$ Notice the bracket is just a number (two dot products divided), and it multiplies the vector b.

The four-step routine

Project \(a = (3, 4)\) onto \(b = (1, 2)\).

  1. Compute \(a \cdot b\): \(3 \times 1 + 4 \times 2 = 3 + 8 = 11\).
  2. Compute \(b \cdot b\): \(1 \times 1 + 2 \times 2 = 1 + 4 = 5\).
  3. Divide to get c: \(c = 11 / 5 = 2.2\).
  4. Multiply b by c: \(2.2 \times (1, 2) = (2.2, 4.4)\).

Always check. The leftover is \(a - (2.2, 4.4) = (0.8, -0.4)\). Its dot product with b is \(0.8 \times 1 + (-0.4) \times 2 = 0.8 - 0.8 = 0\). Perpendicular, as it must be.

Common slips. Dividing by \(a \cdot a\) instead of \(b \cdot b\): the denominator always uses the vector you project onto. Stopping at c: the projection is a vector, \(c\,b\), not the number c.

Reading the number c

  • \(c \gt 0\): the shadow points the same way as b.
  • \(c = 0\): a is perpendicular to b, and the shadow is the zero vector.
  • \(c \lt 0\): the shadow points opposite to b.

The projection is also the closest point to a on the line of b. Any other point on that line is further away, because the perpendicular route is the shortest. That "closest point" idea is exactly what least squares regression uses.

Lesson 1.7 New

Linear combinations and span

Goal: build a target vector out of two given vectors, and say which targets are reachable.

A model's prediction is a mix of its feature columns: so much of this column plus so much of that one. Asking "can the model fit this data?" is the same as asking "can I reach this target by mixing these vectors?". The words for this are linear combination and span, and they are used on almost every page of a linear algebra text.

  • Now drag the tip of w until it lies on the same line as v (for example v = (2, 1) and w = (−2, −1)). Can you still hit the target? Where can the green dot go?

What a linear combination is

Take some vectors. Scale each one by a number of your choice. Add the results. That is a linear combination. It uses only the two operations from Lesson 1.2.

With two vectors v and w and two numbers \(c_1\) and \(c_2\): $$c_1 v + c_2 w$$ The numbers \(c_1, c_2\) are called coefficients or weights.

Computing one, step by step

Take \(v = (1, 2)\), \(w = (3, 1)\), \(c_1 = 2\), \(c_2 = 1\).

  1. Scale v: \(2 \times (1, 2) = (2, 4)\).
  2. Scale w: \(1 \times (3, 1) = (3, 1)\).
  3. Add: \((2 + 3,\ 4 + 1) = (5, 5)\).

So \(2v + 1w = (5, 5)\).

The reverse question: which coefficients hit a target?

Now you are given the target \((5, 5)\) and must find \(c_1\) and \(c_2\) with \(c_1 (1, 2) + c_2 (3, 1) = (5, 5)\). This is the question the lab asks, done with algebra.

  1. Write the combination in components. \(c_1 (1, 2) + c_2 (3, 1) = (c_1 + 3c_2,\ 2c_1 + c_2)\).
  2. Match each component to the target. First components: \(c_1 + 3c_2 = 5\). Second components: \(2c_1 + c_2 = 5\). Two equations, two unknowns.
  3. Solve the first equation for \(c_1\): \(c_1 = 5 - 3c_2\).
  4. Substitute into the second: \(2(5 - 3c_2) + c_2 = 5\), so \(10 - 6c_2 + c_2 = 5\), so \(10 - 5c_2 = 5\), so \(c_2 = 1\).
  5. Go back for \(c_1\): \(c_1 = 5 - 3 \times 1 = 2\).
  6. Check: \(2(1, 2) + 1(3, 1) = (2, 4) + (3, 1) = (5, 5)\).

Notice what just happened: a question about vectors turned into a system of linear equations. That link is the heart of Part B.

Span: everything you can reach

The span of a set of vectors is the set of all their linear combinations: every point you could land on by choosing the coefficients freely.

You haveTheir span
one non-zero vector vthe line through the origin in the direction of v
two vectors that point along different linesthe whole plane \(\mathbb{R}^2\): any target can be hit
two vectors on the same line (one is a multiple of the other)still only that line: the second vector adds nothing new

The third row is what the lab's last experiment shows. Two vectors on the same line are called linearly dependent: one of them is redundant. Two vectors that are not on the same line are linearly independent: each contributes a direction the other cannot. You will meet these two terms properly in Part B; for now the picture is enough.

In data terms: if one feature column is just 2 times another (say, a length in metres and the same length in half-metres), the second column gives the model no new information.

Solutions

1. \((3, 0) + (0, 2) = (3, 2)\).

2. \((2, 4) - (3, 1) = (-1, 3)\). Subtracting is a combination with coefficient −1.

3. Components: \(c_1 + c_2 = 4\) and \(c_1 - c_2 = 2\). Add the two equations: \(2c_1 = 6\), so \(c_1 = 3\). Then \(c_2 = 4 - 3 = 1\). Check: \(3(1, 1) + 1(1, -1) = (3, 3) + (1, -1) = (4, 2)\).

4. Components: \(c_1 + 2c_2 = 3\) and \(2c_1 + 4c_2 = 5\). Double the first equation: \(2c_1 + 4c_2 = 6\). But the second says the same left side equals 5. Both cannot be true, so no combination works. The reason: (2, 4) is 2 times (1, 2), so both lie on one line, and (3, 5) is not on that line.

5. All multiples \(c\,(1, 2) = (c, 2c)\): the line through the origin where the second component is always twice the first.

6. \(7(1, 0) + 3(0, 1) = (7, 3)\). The coefficients are the components themselves. (1, 0) and (0, 1) are called the standard basis vectors; every vector is automatically a combination of them.

Lesson 1.8

Matrix times vector, row by row

Goal: multiply any matrix by a vector correctly, using a size check and one row at a time.

Put your whole dataset in a matrix X, one row per example. Put the model's weights in a vector w. Then \(Xw\) is the prediction for every example at once. This one product is the forward pass of linear regression, and the first step of every layer in a neural network.

Warm-up, before you read on

Try this from memory, on paper. If it goes wrong, good: the lesson is built to fix exactly that.

$$\begin{pmatrix} 2 & 1 \\ 0 & 3 \\ 5 & 2 \end{pmatrix} \begin{pmatrix} 4 \\ 2 \end{pmatrix} = \ ?$$

Answer

(10, 6, 24). Three rows, so three entries. Row 1: \(2 \times 4 + 1 \times 2 = 10\). Row 2: \(0 \times 4 + 3 \times 2 = 6\). Row 3: \(5 \times 4 + 2 \times 2 = 24\).

What a matrix is

A matrix is a rectangular table of numbers. Its shape is written rows × columns, always in that order.

$$X = \begin{pmatrix} 3 & 1 \\ 2 & 4 \\ 0 & 5 \end{pmatrix}$$ This matrix has 3 rows and 2 columns, so its shape is 3 × 2 (read "three by two"). The entry in row i and column j is written \(x_{ij}\): here \(x_{21} = 2\) (row 2, column 1) and \(x_{32} = 5\) (row 3, column 2).

Reading it as data. Each row is one example, each column is one feature. Say the rows are three stores and the columns are how many units of product A and product B each store sold. Then row 1 says store 1 sold 3 of A and 1 of B. Each row is a vector, exactly as in Lesson 1.1.

The product, in words

To multiply a matrix by a vector, take the dot product of each row with the vector. Each row gives one number. Stack those numbers and you have the answer.

With prices \(w = (2, 5)\) for products A and B, \(Xw\) is each store's revenue: quantities dotted with prices, once per store.

The three-step routine

  1. Size check. Count the columns of the matrix and the entries of the vector. They must be equal, or the product does not exist. Then count the rows: the answer will have exactly that many entries. Write that number down before calculating.
  2. One row at a time. Cover every row except one with your hand or a sheet of paper. Take the dot product of the visible row with the vector: first with first, second with second, add.
  3. Move down and repeat until every row is done. Check that you have as many entries as you predicted in step 1.
LAB 1.8 · step through a product one row at a time
  • For each new problem, predict the number of entries and the next row's value on paper before pressing Next step.
  • Do five new problems in a row without a mistake.

Worked example, fully written out

$$\begin{pmatrix} 3 & 1 \\ 2 & 4 \\ 0 & 5 \end{pmatrix} \begin{pmatrix} 2 \\ 5 \end{pmatrix}$$

  1. Size check. The matrix has 2 columns and the vector has 2 entries: allowed. The matrix has 3 rows: the answer has 3 entries.
  2. Row 1 is (3, 1). \(3 \times 2 + 1 \times 5 = 6 + 5 = 11\).
  3. Row 2 is (2, 4). \(2 \times 2 + 4 \times 5 = 4 + 20 = 24\).
  4. Row 3 is (0, 5). \(0 \times 2 + 5 \times 5 = 0 + 25 = 25\).
  5. Stack them: the answer is (11, 24, 25). Three entries, as predicted.

Store 1 earned 11, store 2 earned 24, store 3 earned 25.

The two slips to guard against. (1) Borrowing a number from a different row while working on a row: covering the other rows prevents it. (2) Working down a column instead of across a row: the size check catches it, because the answer would come out with the wrong number of entries.

The general formula

For a matrix A with m rows and n columns, and a vector x with n entries, the product \(Ax\) has m entries, and entry i is $$ (Ax)_i = a_{i1}x_1 + a_{i2}x_2 + \dots + a_{in}x_n = \sum_{j=1}^{n} a_{ij}\,x_j$$ In words: entry i of the answer is row i of A dotted with x.

From revenue to predictions

A linear model with weights w and bias b predicts \(\hat{y} = w \cdot x + b\) for one example (Lesson 1.4). For a whole dataset X, do every row at once: $$\hat{y} = Xw + b$$ where the bias is added to every entry.

Example: \(X = \begin{pmatrix} 1 & 2 \\ 2 & 0 \\ 3 & 1 \end{pmatrix}\), \(w = (10, 5)\), bias 2. Rows: \(10 + 10 = 20\), \(20 + 0 = 20\), \(30 + 5 = 35\). Add 2 to each: predictions (22, 22, 37).

Lesson 1.9 New

Matrix times vector, column view

Goal: see \(Ax\) as a mix of the columns of A, and use that to say which outputs are possible.

The row view tells you how to compute. The column view tells you what the answer means: every output of a linear model is a combination of its feature columns. That single picture explains when a system of equations has a solution, what least squares does, and later what eigenvectors are.

Before starting. Only begin this lesson once Lab 1.8 feels routine. The column view is a second way of looking at the same product, and it is confusing if the row routine is still shaky.

The same product, organised differently

Take \(A = \begin{pmatrix} 3 & 1 \\ 2 & 4 \end{pmatrix}\) and \(x = (2, 5)\). The columns of A are \((3, 2)\) and \((1, 4)\): read each one downward.

Row view (Lesson 1.8). Row 1: \(3 \times 2 + 1 \times 5 = 11\). Row 2: \(2 \times 2 + 4 \times 5 = 24\). Answer (11, 24).

Column view. Use the entries of x as coefficients for the columns:

  1. Scale column 1 by \(x_1 = 2\): \(2 \times (3, 2) = (6, 4)\).
  2. Scale column 2 by \(x_2 = 5\): \(5 \times (1, 4) = (5, 20)\).
  3. Add: \((6 + 5,\ 4 + 20) = (11, 24)\).

The same answer. In general $$Ax = x_1\,(\text{column 1}) + x_2\,(\text{column 2}) + \dots + x_n\,(\text{column } n)$$ So \(Ax\) is a linear combination of the columns of A, with the entries of x as the coefficients. This is Lesson 1.7 again, with the two vectors stored side by side in a matrix.

Why the two views always agree

Write the product with letters, \(A = \begin{pmatrix} a & b \\ c & d \end{pmatrix}\) and \(x = (x_1, x_2)\), and compute both ways.

  1. Row view: \(Ax = (a x_1 + b x_2,\ \ c x_1 + d x_2)\).
  2. Column view: \(x_1 (a, c) + x_2 (b, d) = (a x_1,\ c x_1) + (b x_2,\ d x_2) = (a x_1 + b x_2,\ \ c x_1 + d x_2)\).

Identical expressions. The row view collects the terms across each row first; the column view collects them down each column first. The arithmetic is the same either way.

What the column view tells you

  • Which outputs are possible. As x varies, \(Ax\) can reach exactly the span of the columns of A, and nothing else. That set is called the column space of A. You only need the name for now.
  • What solving \(Ax = b\) means. "Find x so that \(Ax = b\)" is the same as "find the coefficients that combine the columns into b". That is the target game from Lab 1.7. A solution exists exactly when b lies in the span of the columns.
  • What a redundant feature is. If one column is a multiple of another, the columns span less than you would expect, and some targets b become unreachable.
  • How to read a matrix quickly. \(A\,(1, 0)\) returns column 1 and \(A\,(0, 1)\) returns column 2. So the columns of a matrix show where it sends the standard basis vectors. Part B builds the whole idea of a matrix as a transformation on this fact.

  5. A has columns (1, 0, 2) and (0, 1, 1). Compute \(A\,(3, -2)\) with the column view. What shape is A?
  6. A data matrix has a column "height in cm" and a column "height in m". Why is that a problem for the column space?
Solutions

1. Rows: \(1 \times 2 + 3 \times 1 = 5\) and \(2 \times 2 + 1 \times 1 = 5\), so (5, 5). Columns: \(2\,(1, 2) + 1\,(3, 1) = (2, 4) + (3, 1) = (5, 5)\).

2. \(A\,(1, 0) = (4, 2)\), the first column. \(A\,(0, 1) = (-1, 5)\), the second column.

3. The columns are (1, 2) and (2, 4). The second is 2 times the first, so their span is one line, the multiples of (1, 2). Is (3, 5) a multiple of (1, 2)? 3 times (1, 2) is (3, 6), not (3, 5). So no solution. This is practice problem 4 of Lesson 1.7 in matrix form.

4. Column view: \(x_1 (1, 1) + x_2 (1, -1) = (4, 2)\). Components: \(x_1 + x_2 = 4\) and \(x_1 - x_2 = 2\). Adding: \(2x_1 = 6\), so \(x_1 = 3\), then \(x_2 = 1\). So \(x = (3, 1)\). Check by rows: \(3 + 1 = 4\) and \(3 - 1 = 2\).

5. \(3\,(1, 0, 2) - 2\,(0, 1, 1) = (3, 0, 6) - (0, 2, 2) = (3, -2, 4)\). A has 3 rows and 2 columns: shape 3 × 2.

6. The cm column is exactly 100 times the m column. The two columns lie on one line, so the second adds no new direction to the column space. The model gains nothing from it, and there is no longer a single best pair of weights for the two columns.

10. Three rows, three entries. \(3 + 8 = 11\); \(6 - 2 = 4\); \(0 + 6 = 6\). Answer (11, 4, 6). 1.8

11. Columns: \(4\,(2, 0) - 1\,(1, 3) = (8, 0) - (1, 3) = (7, -3)\). Rows: \(8 - 1 = 7\) and \(0 - 3 = -3\). 1.9

12. The weight vector has 4 entries, one per feature column. The result has 6 entries, one per row. Each entry is the model's weighted total for that example. 1.8

Cheat sheet

Vectors

\(a + b = (a_1 + b_1,\ a_2 + b_2)\)
\(c\,a = (c\,a_1,\ c\,a_2)\)
\(a - b\): arrow from tip of b to tip of a
same number of components required

Length and distance

\(\lVert v \rVert = \sqrt{v_1^2 + \dots + v_n^2}\)
distance \(= \lVert a - b \rVert\)
unit vector: \(\hat{v} = v / \lVert v \rVert\)

Dot product

\(a \cdot b = \sum a_i b_i\) (a number)
\(a \cdot a = \lVert a \rVert^2\)
\(a \cdot b = \lVert a \rVert \lVert b \rVert \cos\theta\)
\(a \cdot b = 0 \iff\) orthogonal
cosine similarity: \(\dfrac{a \cdot b}{\lVert a \rVert \lVert b \rVert}\)

Projection of a onto b

\(c = \dfrac{a \cdot b}{b \cdot b}\)
projection \(= c\,b\)
check: \((a - c\,b) \cdot b = 0\)

Combinations and span

\(c_1 v + c_2 w\): a linear combination
span: all reachable points
same line: dependent, span is that line
different lines: independent, span is \(\mathbb{R}^2\)

Matrix times vector

shape: rows × columns
columns of A = entries of x
result: one entry per row
row view: \((Ax)_i = \text{row}_i \cdot x\)
column view: \(Ax = x_1\,\text{col}_1 + \dots + x_n\,\text{col}_n\)
predictions: \(\hat{y} = Xw + b\)
