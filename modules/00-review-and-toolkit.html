Lesson 0.1

Reading math notation

Goal: read a line of ML math aloud without stalling on the symbols.

Most of the difficulty in ML papers and textbooks is vocabulary. The formula \(\hat{y}_i = w x_i + b\) says "the prediction for example number i is the weight times that example's input, plus the bias". Nothing more.

The symbols you will meet most

\(\hat{y}\)y hat: a predicted value\(y\) is the truth, \(\hat{y}\) is the model's guess

Worked example

Read this aloud: $$\text{MSE} = \frac{1}{n}\sum_{i=1}^{n}\,(y_i - \hat{y}_i)^2$$

"For each of the n examples, take the true value minus the predicted value and square it. Add all of those up and divide by n." That is mean squared error, the loss you will minimise in Lesson 0.4.

Practice on paper

  1. Write in words: \(\ \forall i,\ x_i \in \mathbb{R}^2\).
  2. Write in symbols: "the mean of y is the sum of all n values of y, divided by n".
  3. If \(x = (4, 7, 1)\), what are \(x_2\) and \(\sum_{i=1}^{3} x_i\)?
  4. Compute \(\prod_{i=1}^{4} i\).
Solutions

1. Every data point \(x_i\) is a pair of real numbers (a point in the plane).

2. \(\bar{y} = \frac{1}{n}\sum_{i=1}^{n} y_i\)

3. \(x_2 = 7\). The sum is \(4+7+1 = 12\).

4. \(1\cdot2\cdot3\cdot4 = 24\) (this is 4 factorial, written \(4!\)).

In \(\hat{y}_i = w x_i + b\), what does the hat tell you?

Lesson 0.2

Exponents, roots, logs

Goal: simplify any expression with powers and logs using six rules.

Likelihoods multiply thousands of tiny probabilities together. Taking a log turns that product into a sum, which is why "log-likelihood" and "cross-entropy" appear everywhere in ML.

The rules

ExponentsLogs (the mirror image)
\(a^m \cdot a^n = a^{m+n}\)\(\log(xy) = \log x + \log y\)
\(\dfrac{a^m}{a^n} = a^{m-n}\)\(\log\!\left(\dfrac{x}{y}\right) = \log x - \log y\)
\((a^m)^n = a^{mn}\)\(\log(x^n) = n\log x\)
\(a^0 = 1,\quad a^{-n} = \dfrac{1}{a^n}\)\(\log 1 = 0,\quad \log\frac{1}{x} = -\log x\)
\(a^{1/2} = \sqrt{a},\quad a^{1/n} = \sqrt[n]{a}\)\(\log_b x = \dfrac{\ln x}{\ln b}\)

The definition that ties them together: \(\log_b x = y\) means \(b^y = x\). A log answers the question "what power do I need?" So \(\log_2 8 = 3\) because \(2^3 = 8\). In ML, \(\log\) with no base almost always means the natural log \(\ln\), base \(e \approx 2.718\).

Simplifying roots

A square root simplifies only when the number inside has a perfect-square factor: \(\sqrt{12} = \sqrt{4\cdot 3} = 2\sqrt{3}\). Factor the number into primes and look for pairs.

Common slip. \(\sqrt{14}\) does not simplify. \(14 = 2\cdot 7\) has no repeated prime, so it stays \(\sqrt{14} \approx 3.742\). Also \(\sqrt{a+b} \ne \sqrt{a}+\sqrt{b}\): check with \(\sqrt{9+16} = 5\), not \(3+4\).

Worked example

Simplify \(\ln\!\left(\dfrac{e^{3}\,x^2}{\sqrt{y}}\right)\).

Split the product and quotient: \(\ln e^3 + \ln x^2 - \ln y^{1/2}\). Bring the powers down: \(3 + 2\ln x - \tfrac12 \ln y\).

Practice on paper

  1. Simplify \(\dfrac{2^5 \cdot 2^{-2}}{2^4}\).
  2. Simplify \(\sqrt{72}\) and \(\sqrt{30}\).
  3. Evaluate \(\log_{10} 1000\), \(\log_2 \tfrac{1}{8}\), \(\ln e^{-2}\).
  4. Write \(\log(p_1 p_2 p_3)\) as a sum.
  5. Solve for x: \(e^{2x} = 7\).
  6. Solve for x: \(\ln(x) + \ln(x-3) = \ln 10\).
Solutions

1. \(2^{5-2-4} = 2^{-1} = \tfrac12\).

2. \(\sqrt{72} = \sqrt{36\cdot2} = 6\sqrt2\). \(\sqrt{30}\) stays as it is, since \(30 = 2\cdot3\cdot5\).

3. \(3\), \(-3\), \(-2\).

4. \(\log p_1 + \log p_2 + \log p_3\). This is exactly how a likelihood becomes a log-likelihood.

5. Take ln of both sides: \(2x = \ln 7\), so \(x = \tfrac12\ln 7 \approx 0.973\).

6. \(\ln\big(x(x-3)\big) = \ln 10\), so \(x^2 - 3x - 10 = 0\), giving \((x-5)(x+2)=0\). Only \(x = 5\) works, because \(\ln\) needs a positive input.

Python

import numpy as np

p = np.array([0.9, 0.8, 0.95, 0.7])     # four small probabilities
print(np.prod(p))                        # product: 0.4788
print(np.sum(np.log(p)))                 # sum of logs: -0.7365
print(np.exp(np.sum(np.log(p))))         # back to 0.4788

# why logs matter: multiply 2000 probabilities
many = np.full(2000, 0.5)
print(np.prod(many))                     # 0.0  (underflow)
print(np.sum(np.log(many)))              # -1386.29, still usable

Which expression equals \(\log(a^2 b)\)?

Lesson 0.3

Functions

Goal: see any function as a machine with an allowed input set, and compose two of them.

A machine learning model is a function: data goes in, a prediction comes out. A neural network is many simple functions composed one after another.

LAB 0.3 · pick a function, slide the input
  • With √x, drag x below zero. What happens, and why?
  • With 1/x, creep toward x = 0 from both sides.
  • With x², find two different inputs that give the same output. Can you do that with x³ − 3x? With √x?

The idea

A function \(f\) assigns exactly one output to each allowed input. The set of allowed inputs is the domain; the set of outputs it can actually produce is the range.

FunctionDomainRange
\(x^2\)all real x\(y \ge 0\)
\(\sqrt{x}\)\(x \ge 0\)\(y \ge 0\)
\(1/x\)\(x \ne 0\)\(y \ne 0\)
\(\ln x\)\(x \gt 0\)all real y
\(e^x\)all real x\(y \gt 0\)

Composition feeds one function's output into another: \((g \circ f)(x) = g(f(x))\). Work from the inside out. Inverse functions undo each other: \(f^{-1}(f(x)) = x\). A function has an inverse only if no two inputs share an output, which is why \(x^2\) needs its domain cut to \(x \ge 0\) before \(\sqrt{\ }\) can undo it.

Worked example

Let \(f(x) = 2x + 1\) and \(g(x) = x^2\).

\(g(f(3)) = g(7) = 49\), while \(f(g(3)) = f(9) = 19\). Order matters.

Inverse of \(f\): write \(y = 2x+1\), solve for x: \(x = \tfrac{y-1}{2}\). So \(f^{-1}(y) = \tfrac{y-1}{2}\). Check: \(f^{-1}(7) = 3\).

Practice on paper

  1. Give the domain of \(h(x) = \dfrac{1}{\sqrt{x-2}}\).
  2. With \(f(x) = 3x - 2\) and \(g(x) = e^x\), write \(g(f(x))\) and \(f(g(x))\).
  3. Find the inverse of \(f(x) = \dfrac{x+4}{3}\).
  4. A layer computes \(z = wx + b\) then \(a = \max(0, z)\). With \(w = 2,\ b = -3\), find a for \(x = 1\) and \(x = 4\).
  5. Is \(f(x) = x^3\) invertible on all of \(\mathbb{R}\)? Is \(f(x) = |x|\)?
Solutions

1. Need \(x - 2 \gt 0\) (root needs \(\ge 0\), and the denominator cannot be zero), so \(x \gt 2\).

2. \(g(f(x)) = e^{3x-2}\). \(f(g(x)) = 3e^{x} - 2\).

3. \(y = \tfrac{x+4}{3} \Rightarrow x = 3y - 4\). So \(f^{-1}(y) = 3y - 4\).

4. \(x=1\): \(z = -1\), \(a = 0\). \(x = 4\): \(z = 5\), \(a = 5\). This "max with zero" is the ReLU activation.

5. \(x^3\) yes: each output comes from exactly one input. \(|x|\) no: \(|3| = |-3|\).

Python

import numpy as np

f = lambda x: 2*x + 1
g = lambda x: x**2

x = np.array([-2, 0, 3])
print(g(f(x)))     # [ 9  1 49]
print(f(g(x)))     # [ 9  1 19]

relu = lambda z: np.maximum(0, z)
print(relu(2*x - 3))   # a one-neuron "network"

For \(f(x) = x + 1\) and \(g(x) = 2x\), what is \(g(f(x))\)?

Lesson 0.4

Lines and your first model

Goal: fit a line to data by hand and measure how wrong it is.

Linear regression is the line \(\hat{y} = wx + b\). Every later model, up to deep networks, is built from this piece. Learning means choosing w and b so the errors are small.

LAB 0.4 · be the learning algorithm: move w and b to shrink the error
  • The orange segments are the errors (residuals). Get the MSE under 0.05 before pressing the button.
  • Change only b. What does the line do? Change only w. What stays fixed?

The idea

In \(y = wx + b\), the slope w is how much y changes when x increases by 1, and the intercept b is the value of y at \(x = 0\). Between two points:

$$w = \frac{\Delta y}{\Delta x} = \frac{y_2 - y_1}{x_2 - x_1}$$

The residual for a data point is \(y_i - \hat{y}_i\): truth minus prediction. Squaring makes every error positive and punishes large misses more. Averaging the squares gives the mean squared error from Lesson 0.1.

Worked example

Line through \((1, 3)\) and \((4, 9)\): slope \(w = \tfrac{9-3}{4-1} = 2\). Then \(3 = 2(1) + b\) gives \(b = 1\). So \(y = 2x + 1\).

MSE of that line on the points \((1, 2), (2, 6), (3, 7)\): predictions are 3, 5, 7. Residuals are \(-1, 1, 0\). Squares are \(1, 1, 0\). MSE \(= \tfrac{2}{3} \approx 0.667\).

Practice on paper

  1. Find the line through \((-2, 5)\) and \((2, -3)\).
  2. A model predicts salary (thousand EGP) as \(\hat{y} = 1.5x + 8\) where x is years of experience. Interpret 1.5 and 8.
  3. For \(\hat{y} = 0.5x + 1\) and data \((2, 3), (4, 2), (6, 5)\), compute the three residuals and the MSE.
  4. Two lines \(y = 2x + 1\) and \(y = -x + 7\). Where do they cross?
  5. What is the slope of a horizontal line? Why can a vertical line not be written as \(y = wx + b\)?
Solutions

1. \(w = \tfrac{-3-5}{2-(-2)} = -2\). \(5 = -2(-2) + b \Rightarrow b = 1\). Line: \(y = -2x + 1\).

2. Each extra year adds 1.5 thousand to the predicted salary. Someone with zero experience is predicted to earn 8 thousand.

3. Predictions 2, 3, 4. Residuals \(1, -1, 1\). MSE \(= \tfrac{1+1+1}{3} = 1\).

4. \(2x + 1 = -x + 7 \Rightarrow x = 2,\ y = 5\).

5. Zero. A vertical line has \(\Delta x = 0\), so the slope would need division by zero; it also fails the one-output-per-input rule for functions.

Python

import numpy as np
import matplotlib.pyplot as plt

x = np.array([1, 2, 3, 4, 5, 6])
y = np.array([2.1, 2.9, 4.2, 4.8, 6.1, 6.9])

def mse(w, b):
    return np.mean((y - (w*x + b))**2)

print(mse(0.2, 4.0))          # a bad guess
w, b = np.polyfit(x, y, 1)    # the best line
print(w, b, mse(w, b))

plt.scatter(x, y); plt.plot(x, w*x + b); plt.show()

Lesson 0.5

Quadratics and the bowl

Goal: find the lowest point of a parabola three ways.

Plot MSE against the slope w and you get a parabola: a bowl with one lowest point. Training a linear model means finding the bottom of that bowl. In Module 1 the characteristic polynomial for eigenvalues of a 2×2 matrix is also a quadratic.

LAB 0.5 · y = ax² + bx + c
  • Make a negative. What happens to the bowl?
  • Raise c until the roots disappear. Watch the discriminant change sign.
  • Move only b. Trace the path the vertex follows.

The idea

For \(y = ax^2 + bx + c\):

  • It opens upward (a bowl, with a minimum) when \(a \gt 0\), downward when \(a \lt 0\).
  • The vertex sits at \(x = -\dfrac{b}{2a}\).
  • The roots (where \(y = 0\)) are \(x = \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}\).
  • The discriminant \(D = b^2 - 4ac\) counts real roots: two if \(D \gt 0\), one if \(D = 0\), none if \(D \lt 0\).

Completing the square rewrites it as \(a(x - h)^2 + k\), where the vertex \((h, k)\) can be read off directly.

Worked example

Minimise \(L(w) = 2w^2 - 12w + 23\).

Vertex formula: \(w = -\tfrac{-12}{2\cdot2} = 3\), and \(L(3) = 18 - 36 + 23 = 5\).

Completing the square: \(2(w^2 - 6w) + 23 = 2\big((w-3)^2 - 9\big) + 23 = 2(w-3)^2 + 5\). The square is never negative, so the minimum is 5 at \(w = 3\).

Third way, with a derivative, comes in Lesson 0.8.

Practice on paper

  1. Solve \(x^2 - 5x + 6 = 0\) by factoring.
  2. Solve \(2x^2 + 3x - 2 = 0\) with the formula.
  3. How many real roots does \(x^2 + 2x + 5\) have?
  4. Complete the square for \(x^2 + 8x + 10\) and state the vertex.
  5. Find the minimum of \(L(w) = 3w^2 - 6w + 7\).
  6. Solve \(\lambda^2 - 7\lambda + 10 = 0\). (You will meet this exact shape when finding eigenvalues.)
Solutions

1. \((x-2)(x-3) = 0\), so \(x = 2\) or \(x = 3\).

2. \(D = 9 + 16 = 25\). \(x = \tfrac{-3 \pm 5}{4}\), so \(x = \tfrac12\) or \(x = -2\).

3. \(D = 4 - 20 = -16 \lt 0\). None.

4. \((x+4)^2 - 16 + 10 = (x+4)^2 - 6\). Vertex \((-4, -6)\).

5. \(w = \tfrac{6}{6} = 1\), \(L(1) = 3 - 6 + 7 = 4\).

6. \((\lambda - 2)(\lambda - 5) = 0\), so \(\lambda = 2\) or \(\lambda = 5\).

print(w[np.argmin(L(w))], L(w).min())   # 3.0  5.0

Lesson 0.6

Exponential, log, sigmoid

Goal: sketch \(e^x\), \(\ln x\) and the sigmoid from memory, with their key values.

The sigmoid squeezes any number into a probability between 0 and 1. That one curve turns a linear model into logistic regression, your first classifier.

LAB 0.6a · bx and logb x are mirror images across y = x
  • Every exponential passes through one fixed point, whatever the base. Which? Every log passes through which?
  • Set the probe to 1, 2, 3. How does bx grow each step? How does that differ from a line?
LAB 0.6b · sigmoid σ(k·(x − c))
  • Push k to its maximum. What does the curve turn into?
  • Whatever k is, what is the output exactly at x = c?

The idea

Exponential \(e^x\): always positive, equals 1 at \(x=0\), and multiplies by the same factor for each unit step. Natural log \(\ln x\): defined only for \(x \gt 0\), equals 0 at \(x = 1\), grows without bound but ever more slowly. They undo each other: \(\ln(e^x) = x\) and \(e^{\ln x} = x\).

The sigmoid (new)

This function is probably new to you. Its job: take any number z, however large or negative, and turn it into a number between 0 and 1, so the result can be read as a probability. Its symbol is \(\sigma\) (lowercase sigma), and its formula is $$\sigma(z) = \frac{1}{1 + e^{-z}}$$

To compute it, do three small steps: find \(e^{-z}\), add 1, then take 1 divided by that. Here it is for five inputs:

z\(e^{-z}\)\(1 + e^{-z}\)\(\sigma(z)\)
−454.655.60.018
−27.398.390.119
0120.500
20.1351.1350.881
40.0181.0180.982

Three things to read from the table:

  • Large positive z gives an output near 1. \(e^{-z}\) becomes tiny, so the bottom of the fraction is barely more than 1.
  • Large negative z gives an output near 0. \(e^{-z}\) becomes huge, so you are dividing 1 by a huge number.
  • At z = 0 the output is exactly 0.5. \(e^{0} = 1\), so the fraction is \(\tfrac{1}{2}\).

One more pattern: opposite inputs give outputs that add up to 1. Compare the rows for 2 and −2: \(0.881 + 0.119 = 1\). Compare 4 and −4: \(0.982 + 0.018 = 1\). This holds for every pair \(z\) and \(-z\). On the graph in Lab 0.6b it means the curve sits as far above 0.5 on the right as it sits below 0.5 on the left, at the same distance from the centre. Written as a formula: \(\sigma(-z) = 1 - \sigma(z)\). People call this the symmetry of the sigmoid.

Why it is useful: if a model says the probability of spam is \(\sigma(z)\), then the probability of not spam is \(1 - \sigma(z)\), and by this pattern that is simply \(\sigma(-z)\). Practice problem 4 below asks you to prove the pattern with algebra; the table is enough to believe it for now.

Worked example

The situation. We want a program that reads an email and gives the probability that it is spam. It uses one piece of information: x, the number of suspicious words in the email (words such as "free", "winner", "urgent"). More suspicious words should mean a higher probability.

The model works in two stages.

  • Stage 1, a score. A line, as in Lesson 0.4, turns the word count into a score: \(z = 0.8x - 2\). The numbers 0.8 and −2 are the model's weight and bias. Here they are simply given to you; in a real model, training finds them. The score can be any number, negative or positive, so it is not a probability yet.
  • Stage 2, a probability. The sigmoid turns that score into a number between 0 and 1: \(p = \sigma(z)\).

Question 1. An email has 5 suspicious words. What is the probability that it is spam?

  1. Find the score: \(z = 0.8 \times 5 - 2 = 4 - 2 = 2\).
  2. Find \(e^{-z}\): \(e^{-2} \approx 0.1353\).
  3. Add 1: \(1 + 0.1353 = 1.1353\).
  4. Divide: \(p = \dfrac{1}{1.1353} \approx 0.881\).

The model says there is about an 88% chance this email is spam. Steps 2 to 4 are the row z = 2 of the table above.

Question 2. How many suspicious words leave the model exactly undecided, at 50%?

  1. From the table, \(\sigma(z) = 0.5\) happens only when the score is \(z = 0\).
  2. So set the score to zero and solve for x: \(0.8x - 2 = 0\).
  3. Add 2 to both sides: \(0.8x = 2\).
  4. Divide by 0.8: \(x = 2.5\).

Reading the answer. Below 2.5 words the score is negative, so the probability is under 50% and the model leans toward "not spam". Above 2.5 words the score is positive, so the probability is over 50% and it leans toward "spam". Word counts are whole numbers, so in practice: 2 or fewer words, not spam; 3 or more, spam. The value where the model switches sides is called the decision boundary.

Practice on paper

  1. Without a calculator: \(e^0\), \(\ln 1\), \(\ln e\), \(e^{\ln 5}\), \(\sigma(0)\).
  2. A value doubles every 3 years. Write it as \(V(t) = V_0 \cdot 2^{t/3}\) and find the growth factor over 9 years.
  3. Solve \(\sigma(z) = 0.9\) for z. (Hint: rearrange to isolate \(e^{-z}\).)
  4. Show that \(\sigma(-z) = 1 - \sigma(z)\).
  5. Which is larger for \(x = 20\): \(x^3\) or \(2^x\)?
Solutions

1. \(1,\ 0,\ 1,\ 5,\ \tfrac12\).

2. \(2^{9/3} = 2^3 = 8\).

3. \(\tfrac{1}{1+e^{-z}} = 0.9 \Rightarrow 1 + e^{-z} = \tfrac{1}{0.9} \Rightarrow e^{-z} = \tfrac19 \Rightarrow z = \ln 9 \approx 2.197\). In general \(z = \ln\tfrac{p}{1-p}\), called the log-odds or logit.

4. \(\sigma(-z) = \tfrac{1}{1+e^{z}}\). Multiply top and bottom by \(e^{-z}\): \(\tfrac{e^{-z}}{e^{-z}+1}\). And \(1 - \sigma(z) = \tfrac{1 + e^{-z} - 1}{1+e^{-z}} = \tfrac{e^{-z}}{1+e^{-z}}\). Equal.

5. \(20^3 = 8000\); \(2^{20} = 1{,}048{,}576\). The exponential wins, and always does eventually.

Python

import numpy as np
import matplotlib.pyplot as plt

sigmoid = lambda z: 1 / (1 + np.exp(-z))

x = np.linspace(0, 8, 200)
plt.plot(x, sigmoid(0.8*x - 2))
plt.axhline(0.5, ls="--"); plt.axvline(2.5, ls="--")

Lesson 0.7

Sigma notation

Goal: expand any \(\sum\) into its terms and collapse a pattern back into a \(\sum\).

A sum over a dataset is a for loop written in math. Loss functions, means, variances, dot products and expected values are all sums.

LAB 0.7 · a sum is a loop: each bar is one term
  • Term 2i − 1. The terms are 1, 3, 5, 7, … (the odd numbers). Set n = 1, 2, 3, 4 and write down the total each time. What pattern do the totals make?
  • Term (1/2)^i, which means \(\tfrac12, \tfrac14, \tfrac18, \tfrac1{16}, \dots\): each term is half the one before. Move n from 1 up to 12 and write down the total each time. Then answer two things: (a) does the total ever go down? (b) is there a number the total never passes, however large n gets? Compare with the 2i − 1 totals, which pass any number you name.
What you should see

2i − 1: totals 1, 4, 9, 16. These are the square numbers: \(\sum_{i=1}^{n} (2i-1) = n^2\). They grow without limit.

(1/2)^i: totals 0.5, 0.75, 0.875, 0.9375, … , about 0.9998 at n = 12. (a) Never down, because every term is positive. (b) It never passes 1: each new term fills exactly half of the gap that is left to 1, like walking half the remaining distance to a wall. So the total rises forever but settles toward 1.

The point: adding infinitely many positive numbers does not have to give infinity. If the terms shrink fast enough, the total levels off. That is called a convergent sum, written \(\sum_{i=1}^{\infty} (1/2)^i = 1\). You will meet it again with the discount factor \(\gamma\) in reinforcement learning, where future rewards are weighted by \(\gamma^t\).

The idea

$$\sum_{i=1}^{n} a_i = a_1 + a_2 + \dots + a_n$$ The letter under the sigma is the loop counter; it starts at the bottom value and stops at the top value. Three rules cover almost everything:

  • Constants come out: \(\sum c\,a_i = c\sum a_i\)
  • Sums split: \(\sum (a_i + b_i) = \sum a_i + \sum b_i\)
  • Summing a constant: \(\sum_{i=1}^{n} c = nc\)

Common slip. \(\sum a_i b_i \ne \left(\sum a_i\right)\left(\sum b_i\right)\) and \(\sum a_i^2 \ne \left(\sum a_i\right)^2\). Check with \(a = (1, 2)\): \(1+4 = 5\) but \((1+2)^2 = 9\).

Statistics in this language: mean \(\bar{x} = \frac1n\sum x_i\), variance \(s^2 = \frac{1}{n-1}\sum (x_i - \bar{x})^2\). And the dot product you already met: \(a\cdot b = \sum a_i b_i\).

Worked example

Data \(x = (2, 4, 9)\). Mean: \(\tfrac{15}{3} = 5\). Deviations: \(-3, -1, 4\) (they always sum to zero). Squares: \(9, 1, 16\). Variance: \(\tfrac{26}{2} = 13\). Standard deviation: \(\sqrt{13} \approx 3.61\).

The second adds the constant 2 ten times: \(10\cdot2 = 20\). Total \(165 + 20 = 185\). Check by listing: \(5 + 8 + 11 + \dots + 32 = 185\).

6. \(\sum x_i - \sum \bar{x} = n\bar{x} - n\bar{x} = 0\), using \(\sum x_i = n\bar{x}\) and the constant rule.

Lesson 0.8

The derivative

Goal: explain a derivative as a slope, and differentiate with four rules.

The derivative of the loss tells the model which way to nudge each weight and by how much. Backpropagation is the chain rule applied many times.

LAB 0.8 · shrink h and watch the secant become the tangent
  • With x², set x = 1 and shrink h. What number does the secant slope approach? Try x = 2, then x = −1. Guess the rule.
  • With x³ − 3x, find the two x values where the tangent is flat. What is special about the curve there?

The idea

The slope between two points on a curve is \(\frac{f(x+h) - f(x)}{h}\). Let the gap h shrink toward zero and that slope settles on a single number, the derivative:

$$f'(x) = \frac{df}{dx} = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$$

It is the slope of the tangent line: how fast the output changes per unit change of input, at that exact point. Positive means rising, negative means falling, zero means flat (a candidate minimum or maximum).

RuleStatementExample
Power\(\frac{d}{dx}x^n = n x^{n-1}\)\(\frac{d}{dx}x^5 = 5x^4\)
Constant, sum\((c f)' = c f'\), \((f+g)' = f' + g'\)\((3x^2 + 4x)' = 6x + 4\)
Exp and log\((e^x)' = e^x\), \((\ln x)' = \frac1x\)
Product\((fg)' = f'g + fg'\)\((x e^x)' = e^x + x e^x\)
Chain\(\big(g(f(x))\big)' = g'(f(x))\cdot f'(x)\)\(\big((3x+1)^2\big)' = 2(3x+1)\cdot 3\)
Exp with a multiplier (the chain rule applied to \(e^{kx}\))\(\big(e^{kx}\big)' = k\,e^{kx}\)\(\big(e^{3x}\big)' = 3e^{3x}\), \(\big(e^{-x}\big)' = -e^{-x}\)
Any other base a (with \(a \gt 0\))\(\big(a^{x}\big)' = a^{x}\ln a\)
\(\big(a^{kx}\big)' = k\,a^{kx}\ln a\)		\(\big(2^{x}\big)' = 2^{x}\ln 2 \approx 0.693\cdot 2^{x}\)
\(\big(10^{3x}\big)' = 3\cdot 10^{3x}\ln 10\)

Where the extra \(\ln a\) comes from. Any positive base can be rewritten with e: since \(a = e^{\ln a}\), we get \(a^{x} = e^{x\ln a}\). That is \(e^{kx}\) with \(k = \ln a\), so the row above gives \(\ln a \cdot e^{x\ln a} = a^{x}\ln a\). The base e is the one case where the extra factor disappears, because \(\ln e = 1\). That is the reason e is the standard base in calculus and ML.

Chain rule in words: derivative of the outside (leave the inside alone), times derivative of the inside.

Worked examples

From the definition. For \(f(x) = x^2\): \(\frac{(x+h)^2 - x^2}{h} = \frac{2xh + h^2}{h} = 2x + h\). As \(h \to 0\) this becomes \(2x\). That is what the lab showed you.

Minimum of a loss. \(L(w) = 2w^2 - 12w + 23\) from Lesson 0.5. \(L'(w) = 4w - 12\). Set it to zero: \(w = 3\). Same answer as the vertex formula, and this method works for curves that are not parabolas.

Chain rule on one squared error. \(L(w) = (y - wx)^2\) with x and y fixed numbers. Outside is \((\cdot)^2\), inside is \(y - wx\). So \(\frac{dL}{dw} = 2(y - wx)\cdot(-x) = -2x(y - wx)\).

Sigmoid, step by step (new material, safe to skip on a first pass). This example uses the sigmoid from Lesson 0.6: \(\sigma(z) = \dfrac{1}{1+e^{-z}}\), the curve that squeezes any number into a value between 0 and 1. If you have not met it before Lesson 0.6, that is expected, and nothing else in this lesson depends on it. We differentiate it because training a classifier needs this slope, and the answer turns out to be unusually simple.

Step 1. Rewrite as a power. \(\sigma(z) = (1+e^{-z})^{-1}\). The outside function is \((\ \cdot\ )^{-1}\). The inside is \(u = 1+e^{-z}\).

Step 2. Differentiate the outside with the power rule, leaving the inside alone: \(-u^{-2} = -(1+e^{-z})^{-2}\).

Step 3. Differentiate the inside, \(1 + e^{-z}\), one piece at a time.

  • The 1 is a constant, so its derivative is 0.
  • \(e^{-z}\) is not the plain \(e^{z}\) from the rules table, because its exponent is \(-z\) and not just \(z\). It is a function inside a function, so it needs the chain rule. The outside is \(e^{(\ \cdot\ )}\). The inside is \(-z\).
    • Derivative of the outside, with the inside left alone: \(e^{-z}\). (e to the power of anything differentiates to itself.)
    • Derivative of the inside: \(-z\) is a line with slope \(-1\), so its derivative is \(-1\).
    • Multiply the two: \(e^{-z}\cdot(-1) = -e^{-z}\).

Adding the pieces, the derivative of the inside is \(0 + (-e^{-z}) = -e^{-z}\). The same reasoning gives a pattern worth remembering, now in the rules table above: \(\big(e^{kx}\big)' = k\,e^{kx}\). Here \(k = -1\).

Step 4. Multiply them. $$\sigma'(z) = -(1+e^{-z})^{-2}\cdot(-e^{-z}) = \frac{e^{-z}}{(1+e^{-z})^2}$$ The two minus signs cancel. This is already a correct answer.

Step 5. Tidy it. This step is optional: Step 4 is already the correct derivative. Step 5 only rewrites it in a shorter form.

5a. Split the fraction in two. The bottom is squared, which means \((1+e^{-z})\) times itself. So the fraction can be written as a product of two fractions: $$\frac{e^{-z}}{(1+e^{-z})^2} = \frac{1}{1+e^{-z}}\cdot\frac{e^{-z}}{1+e^{-z}}$$ Check it by multiplying back: tops give \(1\cdot e^{-z}\), bottoms give \((1+e^{-z})^2\).

5b. Recognise the first factor. \(\dfrac{1}{1+e^{-z}}\) is the definition of \(\sigma(z)\).

5c. Find out what the second factor is. Work out \(1 - \sigma(z)\) and see what you get. Start from $$1 - \sigma(z) = 1 - \frac{1}{1+e^{-z}}$$ To subtract, both parts need the same bottom, so write the 1 as \(\dfrac{1+e^{-z}}{1+e^{-z}}\): $$\frac{1+e^{-z}}{1+e^{-z}} - \frac{1}{1+e^{-z}} = \frac{1 + e^{-z} - 1}{1+e^{-z}} = \frac{e^{-z}}{1+e^{-z}}$$ That is exactly the second factor. So the second factor equals \(1 - \sigma(z)\).

5d. Put the two together. $$\sigma'(z) = \sigma(z)\,\big(1 - \sigma(z)\big)$$

Check with numbers. Recall the main idea of this lesson: the derivative at a point is the slope of the curve at that point, meaning how fast the output changes when the input changes a little. So \(\sigma'(z)\) is the slope of the sigmoid curve at z. To get it at a particular z, put that z into the formula we just found.

At z = 0. From Lesson 0.6, \(\sigma(0) = 0.5\). Then $$\sigma'(0) = \sigma(0)\,\big(1 - \sigma(0)\big) = 0.5 \times (1 - 0.5) = 0.5 \times 0.5 = 0.25$$ So the slope of the sigmoid at z = 0 is 0.25.

What a slope of 0.25 means. Near z = 0, each small step in z raises the output by about a quarter of that step. Move z from 0 to 0.1 and the output should rise by about \(0.25 \times 0.1 = 0.025\), from 0.5 to about 0.525. The true value is \(\sigma(0.1) = 0.52498\). The formula predicts it correctly.

At z = 2. \(\sigma(2) = 0.881\), so \(\sigma'(2) = 0.881 \times (1 - 0.881) = 0.881 \times 0.119 \approx 0.105\). The slope is smaller here, which matches the picture: the curve is steepest in the middle and flattens out toward the ends. You can see both in Lab 0.6b with k = 1 and c = 0; its readout shows the slope at the centre as k/4 = 0.25.

Why this result is used so much. The slope is computed from the output alone: once a model has produced \(\sigma(z)\), its derivative costs one subtraction and one multiplication. You will meet this identity again in logistic regression and backpropagation, and it will be derived again there.

Lesson 0.9

Gradient descent preview

Goal: run gradient descent by hand for three steps and say what the learning rate does.

Setting the derivative to zero and solving works for a parabola. A neural network has millions of weights and no formula for the bottom, so instead we walk downhill a step at a time. This is how nearly every modern model is trained. Module 3 covers it fully; this is the first taste.

LAB 0.9 · L(w) = (w − 2)² + 1, walking downhill
  • η = 0.1: how many steps to get within 0.01 of the minimum?
  • η = 0.5: what happens on the very first step? Can you explain it from the update rule?
  • η = 0.9, then η = 1.05. Describe each behaviour in one word.

The idea

The derivative points uphill: where \(L'(w) \gt 0\), increasing w raises the loss. So step the opposite way:

$$w_{\text{new}} = w_{\text{old}} - \eta\, L'(w_{\text{old}})$$

\(\eta\) (eta) is the learning rate, the step size. The step is automatically large where the slope is steep and small near the flat bottom. Too small an \(\eta\) is slow; too large overshoots and can diverge.

With more than one weight, each weight gets its own derivative, taken while holding the others fixed. That is a partial derivative, written \(\frac{\partial L}{\partial w}\). Collect them into a list and you have the gradient \(\nabla L\), which Module 2 develops in full.

Worked example

\(L(w) = (w-2)^2 + 1\), so \(L'(w) = 2(w - 2)\). Start at \(w_0 = 5\) with \(\eta = 0.25\).

Partial derivatives. For \(L(w, b) = (y - wx - b)^2\) with x, y fixed: \(\frac{\partial L}{\partial w} = -2x(y - wx - b)\) and \(\frac{\partial L}{\partial b} = -2(y - wx - b)\). Same chain rule; the only change is which letter you treat as the variable.

Solutions

1. \(L' = 2w - 6\). Step 1: \(0 - 0.1(-6) = 0.6\). Step 2: \(0.6 - 0.1(-4.8) = 1.08\). Step 3: \(1.08 - 0.1(-3.84) = 1.464\). Heading toward 3.

2. Step 1: \(0 - (-6) = 6\). Step 2: \(6 - 6 = 0\). Step 3: \(6\). It bounces between 0 and 6 forever, never reaching 3.

3. \(w_{new} - 2 = w - 2 - 2\eta(w-2) = (1-2\eta)(w-2)\). Converges when \(|1 - 2\eta| \lt 1\), that is \(0 \lt \eta \lt 1\). At \(\eta = 0.5\) the factor is zero: one step lands exactly on the minimum.

4. \(\frac{\partial f}{\partial x} = 6xy - 5\). \(\frac{\partial f}{\partial y} = 3x^2 + 3y^2\).

5. \(\hat{y} = 3\), residual \(= 4\). \(\frac{\partial L}{\partial w} = -2(2)(4) = -16\). \(\frac{\partial L}{\partial b} = -2(4) = -8\). New \(w = 1 + 0.05\cdot16 = 1.8\). New \(b = 1 + 0.05\cdot 8 = 1.4\). New prediction \(= 5.0\), closer to 7.

Python

import numpy as np

x = np.array([1, 2, 3, 4, 5, 6])
y = np.array([2.1, 2.9, 4.2, 4.8, 6.1, 6.9])

w, b, eta = 0.0, 0.0, 0.02
for step in range(2000):
    resid = y - (w*x + b)
    dw = -2 * np.mean(x * resid)     # dMSE/dw
    db = -2 * np.mean(resid)         # dMSE/db
    w, b = w - eta*dw, b - eta*db

print(w, b)                  # about 0.98  1.08
print(np.polyfit(x, y, 1))   # the exact answer, for comparison
